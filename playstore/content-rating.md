# Google Play content declarations — OhmLauncher

These are the final answers for the current `playRelease` artifact. Do not copy answers from the full GitHub edition.

## Ads

- Contains ads: **No**.

## Target audience

- 13–15: **Selected**.
- 16–17: **Selected**.
- 18 and over: **Selected**.
- Under 13 groups: **Not selected**.
- Store presence likely to appeal to children: **No**.

OhmLauncher is a general-audience Android home launcher intended for teens and adults. It is not designed for children.

## IARC questionnaire — final answers

- Violence: **No**.
- Sexual content or nudity: **No**.
- Profanity or crude humor: **No**.
- Drugs, alcohol, or tobacco: **No**.
- Gambling: **No**.
- Fear or horror: **No**.
- Public user-generated content: **No**.
- Public exchange of information: **No**.
- Location sharing: **No**.
- Digital purchases: **No**.
- Ads: **No**.
- Unrestricted web access: **No**.

The terminal only exposes supported local commands; it is not a web browser. Optional Omarchy pairing synchronizes themes and backgrounds directly with a user-controlled computer on the same local network. It does not provide chat, public content, file transfer, screen sharing, clipboard sharing, notification sharing, or remote control in the Play edition.

## App access

- Are all app features available without special access? **Yes** for review purposes: no account, membership, purchase, or developer credential is required.
- Core launcher, theme, widget, terminal, wallpaper, search, and accessibility-button behavior can be reviewed without pairing.
- Optional Omarchy synchronization requires the reviewer to run the companion on a computer on the same local network and scan its QR code. Use `reviewer-instructions.md`; no credentials are supplied or required.
